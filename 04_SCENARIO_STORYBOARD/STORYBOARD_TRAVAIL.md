# Storyboard de travail — 180 secondes

Ce découpage est une base de production, pas encore un storyboard plan par plan validé. Les durées peuvent être ajustées en animatique sans changer les événements du scénario.

| Temps | Séquence | Intention visuelle / sonore |
|---|---|---|
| 0:00–0:08 | Présent, quartier | Plan d'ensemble du quartier, sons de circulation et de jeu. |
| 0:08–0:18 | Agent au travail | Plan moyen de l'agent municipal dans son activité. |
| 0:18–0:30 | Les enfants jouent | Le ballon et les voix attirent son regard ; raccord de regard vers le souvenir. |
| 0:30–0:40 | Entrée dans le souvenir | Transition sonore et lumineuse vers le terrain adolescent. |
| 0:40–1:05 | Match de quartier | Dribbles lisibles, réactions des adversaires et spectateurs, énergie musicale. |
| 1:05–1:15 | Célébration | Entraîneur fier, coéquipiers heureux, Amadou rayonnant. |
| 1:15–1:25 | Maison | Transition vers le foyer, ambiance plus calme. |
| 1:25–1:55 | Discussion mère-fils | Champ/contrechamp et gros plans ; affection et fermeté coexistent. |
| 1:55–2:10 | Le renoncement | Ballon délaissé, cahiers ouverts, temps qui passe. |
| 2:10–2:25 | Adulte | Transition visuelle vers le travail d'agent municipal. |
| 2:25–2:40 | Retour présent | Même quartier ; le regard d'Amadou revient vers les enfants. |
| 2:40–2:50 | Appel du collègue | Réplique exacte : « Allez, au boulot, on a du travail ! » |
| 2:50–2:56 | Dernier regard | Il regarde une dernière fois les enfants, puis reprend son travail. |
| 2:56–3:00 | Écran noir | Les deux phrases finales apparaissent, sans dialogue supplémentaire. |

## Principes de mise en scène
- Plans larges pour situer le terrain et le quartier.
- Plans rapprochés pour les émotions.
- Dribbles compréhensibles spatialement ; éviter les coupes qui rendent l'action confuse.
- Le match doit montrer le talent sans transformer le film en publicité sportive.
- La scène avec la mère doit être intime, sans la juger.
- Le passage du temps doit être simple et immédiatement compréhensible.

## À produire
1. Vignettes dessinées ou images de storyboard pour chaque plan.
2. Animatique avec durées provisoires.
3. Voix temporaires et sons de référence.
4. Validation du rythme avant animation détaillée.

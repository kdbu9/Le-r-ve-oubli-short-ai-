# LE RÊVE OUBLIÉ — Dossier de production pour Claude Code

Bienvenue dans le dossier de référence du court-métrage d'animation 3D **Le rêve oublié**.

## Comment utiliser ce dossier
1. Ouvrir ce dossier comme projet dans Claude Code.
2. Lire intégralement `CLAUDE.md` à la racine.
3. Lire ensuite `00_PILOTAGE/BRIEF_PROJET.md`, puis les documents spécialisés.
4. Examiner les images de `01_DIRECTION_ARTISTIQUE/REFERENCES_VISUELLES/`.
5. Commencer uniquement par la préproduction et un prototype de validation. Ne pas lancer de rendu final ni de production massive sans validation humaine.

## Règle de priorité
En cas de contradiction, appliquer cet ordre :
1. `00_PILOTAGE/BRIEF_PROJET.md` et `04_SCENARIO_STORYBOARD/SCENARIO_VERROUILLE.md` pour l'histoire et la fin.
2. `01_DIRECTION_ARTISTIQUE/BIBLE_GRAPHIQUE.md` pour l'identité visuelle.
3. Les documents spécialisés.
4. Les images générées, qui sont des références d'ambiance et de style, jamais des sources de scénario.

## Statut des éléments
- **Validé** : histoire générale, cadre français populaire, public enfants + lecture adulte, fin exacte, style 3D stylisé chaleureux, apparence générale de la mère telle que présentée dans sa planche.
- **Référence appréciée / à reproduire** : apparence générale d'Amadou adulte et adolescent et style graphique de sa planche.
- **À confirmer** : prénom définitif du protagoniste (Amadou est un nom de travail présent dans les images), origines précises, certains détails physiques et costumes, dialogues exacts hors répliques déjà validées.
- **À concevoir** : modèles 3D, rig, décors finaux, storyboard détaillé, animatique, musique originale, montage.
